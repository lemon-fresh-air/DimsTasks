# Стабільні версії

## v0.21 — 3 листопада 2026

- Секції списків і проєктів мають спільний вигляд; заголовок згортає секцію, а окремий плюс відкриває коротку форму створення завдання або кроку в цій секції.
- У КП можна вибрати секцію для нового кроку. У НаКП назви секцій редагуються прямо в полі.
- У редакторі завдання значок списку відкриває список, а вибір списку лишається у дропдауні.
- У глобальних налаштуваннях можна ввімкнути показ лише перших трьох кроків КП; за замовчуванням показуються всі.

Стан випуску зафіксовано тегом Git `v0.21`. Опублікована версія збирається з `main` через GitHub Actions.

## v0.20 — 3 листопада 2026

- Поля дати й списку на екрані завдання мають білу поверхню у світлій темі.
- Календар починається з понеділка поточного тижня й показує вибраний у налаштуваннях період уперед.
- Довгий дотик до дати відкриває вибір часу; «Готово» зберігає дату й час та повертає до завдання. Вибір часу плавно відкривається і закривається.

Стан випуску зафіксовано тегом Git `v0.20`. Опублікована версія збирається з `main` через GitHub Actions.

## v0.19 — 3 листопада 2026

- Вікно редагування опису завдання підлаштовується під мобільну клавіатуру; кнопки розташовані одразу після тексту.
- Відновлюючи видалене завдання з денної групи, можна вибрати, чи повертати його в групу.

Стан випуску зафіксовано тегом Git `v0.19`. Опублікована версія збирається з `main` через GitHub Actions.

## v0.18 — 3 листопада 2026

- У кольоровій групі можна швидко створити завдання з назвою та описом; довгі назви груп обрізаються, а лічильник залишається видимим.
- У меню завдання додано видалення з трисекундним скасуванням.
- Завдання в кольоровій групі після завершення плавно підтягуються вгору.

Опублікована версія збирається з `main` через GitHub Actions.

## v0.17.0 — 3 листопада 2026

- Екран завдання став компактнішим: назва, опис і дії мають чіткішу ієрархію та спільні кольори зі списками.
- Опис редагується в окремому вікні; у завданні видно початок довгого тексту з плавним обрізанням, а копіювання бере повний опис.
- Дії з проєктом перенесено в меню з трьома крапками у верхній частині завдання.

Стан випуску зафіксовано тегом Git `v0.17.0`. Опублікована версія збирається з `main` через GitHub Actions.

## v0.16.0 — 3 листопада 2026

- У проєктах з’явилися секції для кроків: їх можна створювати, згортати, перейменовувати, видаляти та переносити між ними завдання.
- Вибрані кроки можна додати на початок або в кінець наявного проєкту чи створити з них новий.
- Поточний крок позначається зеленою зірочкою; після перетворення проєкту на завдання або кроку на проєкт на телефоні відкривається новий об’єкт.
- Покращено керування календарем у виборі дати.

Стан випуску зафіксовано тегом Git `v0.16.0`. Опублікована версія збирається з `main` через GitHub Actions.

## v0.15.0 — 30 жовтня 2026

- У звичайних списках можна створювати, перейменовувати, впорядковувати й видаляти секції. Завдання в секціях можна згортати, а біля заголовка видно їхню кількість.
- Редактор завдання пропонує секцію після вибору списку, що має секції. На екранах «Сьогодні» та «Завтра» поряд зі списком показується секція; довгий підпис обрізається в один рядок.
- У режимі виділення завдання можна перетягувати в межах секції, між секціями та між секцією й областю без секції.
- У головному меню прибрано дубль «Сьогодні»; керування секціями списку отримало компактні кнопки.

Стан випуску зафіксовано тегом Git `v0.15.0`. Опублікована версія збирається з `main` через GitHub Actions.

## v0.14.0 — 30 жовтня 2026

- У календарі можна вибрати рухомий період: місяць, три, два або один тиждень; дати попереднього місяця позначені сірим.

- Покращено перетягування кольорових груп, форматування опису й автоматичне створення нумерованих списків.
- Enter на мобільній клавіатурі підтверджує вибраний час.

Стан випуску зафіксовано тегом Git `v0.14.0`. Опублікована версія збирається з `main` через GitHub Actions.

## v0.13.0 — 30 жовтня 2026

- Існуюче завдання можна прикріпити до активного проєкту безпосередньо з редактора завдання.
- У картці завдання іконка проєкту відкриває проєкт, а назва відкриває список активних проєктів для перепризначення.
- У проєкті можна виділити кілька кроків і перенести їх у новий проєкт зі збереженням даних та порядку.
- Вікно прикріплення завдань до проєкту підлаштовується під видиму область над мобільною клавіатурою.
- Іконка від’єднання від проєкту має позначку мінуса.

Стан випуску зафіксовано тегом Git `v0.13.0`. Опублікована версія збирається з `main` через GitHub Actions.
