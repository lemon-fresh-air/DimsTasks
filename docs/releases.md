# Стабільні версії

## v0.24 — 6 листопада 2026

- Кнопки панелей вибору мають розмір 48 × 48 px і проміжки між ними щонайменше 12 px по горизонталі та вертикалі.
- З ВП можна відкрити ГМ свайпом вправо у вільній області зверху або під проєктами. Свайп вліво з ГМ повертає на ВП; картки та проміжки між ними не запускають цей жест.

Стан випуску зафіксовано тегом Git `v0.24`. Опублікована версія збирається з `main` через GitHub Actions.

## v0.23 — 6 листопада 2026

- У кожному КП зверху є системна секція «Звичайні кроки» для кроків без секції. Її можна згортати, а кроки — переносити між нею та іншими секціями.
- Короткий дотик до плюса секції швидко створює крок; довгий відкриває пошук наявних завдань із множинним вибором. Кнопка додавання залишається видимою над мобільною клавіатурою.
- Перемикач «Нові завдання — на початок» розміщено в НаКП. Він також визначає порядок перенесення вибраних кроків до наявного проєкту.
- МеДО для вибраних кроків КП дає змогу перенести їх до наявного чи нового проєкту або масово відкріпити. У решті панелей виділення є кнопка «⋯» із повідомленням «В розробці»; кнопки дій вирівняно за розміром 44 × 44 px.
- Список для нових завдань у НаКП має білу поверхню й рамку у світлій темі. Резервна копія формату 22 зберігає стан згортання «Звичайних кроків».

Стан випуску зафіксовано тегом Git `v0.23`. Опублікована версія збирається з `main` через GitHub Actions.

## v0.22 — 4 листопада 2026

- Секціями списків і проєктів можна керувати безпосередньо на їхніх екранах: додавати вибрані завдання в нову чи наявну секцію, виділяти й перетягувати секції, перейменовувати, розпускати або видаляти разом із завданнями після підтвердження.
- Дії секцій обмежені своїм списком або проєктом; прив’язки до списків і проєктів незалежні. Секції на КП мають той самий вигляд, що й у списках.
- НаКП спрощено: дії перенесено в меню, опис редагується окремо, відлік доступний у виборі дати; поле мети прибрано з інтерфейсу зі збереженням наявних даних.
- Enter зберігає завдання у короткій формі. Форма підлаштовується під клавіатуру; автозаповнення вимкнене.

Перевірено: збірка, синтаксис JS, 102 модельні тести та 8 браузерних сценаріїв. Жести на фізичному телефоні, service worker, офлайн та встановлення потребують ручної перевірки.
Стан випуску зафіксовано тегом Git `v0.22`. Опублікована версія збирається з `main` через GitHub Actions.

## v0.21 — 3 листопада 2026

- Секції списків і проєктів мають спільний вигляд; заголовок згортає секцію, а окремий плюс відкриває коротку форму створення завдання або кроку в цій секції.
- У КП можна вибрати секцію для нового кроку. У НаКП назви секцій редагуються прямо в полі.
- У редакторі завдання значок списку відкриває список, а вибір списку лишається у дропдауні.
- У глобальних налаштуваннях можна ввімкнути показ лише перших трьох кроків КП; за замовчуванням показуються всі.

Стан випуску зафіксовано тегом Git `v0.21`. Опублікована версія збирається з `main` через GitHub Actions.

## v0.20 — 3 листопада 2026

## v0.15.0 — 30 жовтня 2026

- У звичайних списках можна створювати, перейменовувати, впорядковувати й видаляти секції. Завдання в секціях можна згортати, а біля заголовка видно їхню кількість.
- Редактор завдання пропонує секцію після вибору списку, що має секції. На екранах «Сьогодні» та «Завтра» поряд зі списком показується секція; довгий підпис обрізається в один рядок.
- У режимі виділення завдання можна перетягувати в межах секції, між секціями та між секцією й областю без секції.
- У головному меню прибрано дубль «Сьогодні»; керування секціями списку отримало компактні кнопки.

Стан випуску зафіксовано тегом Git `v0.15.0`. Опублікована версія збирається з `main` через GitHub Actions.
