# Продукт (заповнити)

- **Користувач і контекст:** хто, де і коли користується (телефон, ПК, як часто).
- **Головна повторювана дія:** що робиться щодня.
- **Перший екран:** що має бути видно одразу.
- **Головна дія:** одна кнопка/жест, який має бути найближчим.
- **Дії за частотою:** часті / рідкі / небезпечні.
- **Візуальний напрям:** 1–2 фрази про характер інтерфейсу.
