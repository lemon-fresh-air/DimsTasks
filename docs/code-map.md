# Мапа JavaScript-коду

- `src/js/db.js` — IndexedDB, сховище та оновлення схеми.
- `src/js/model.js` — моделі завдань, списків і проєктів, обчислення та правила порядку.
- `src/js/import-export.js` — резервні копії, експорт та імпорт.
- `src/js/ui.js` — спільні елементи інтерфейсу (`els`), відображення завдань і списків, форматування дат.
- `src/js/gestures.js` — свайпи й перетягування завдань, списків і карток проєктів.
- `src/js/date-picker.js` — стан і відображення календаря та діалогу вибору часу.
- `src/js/projects.js` — екрани проєктів, редактор і дії з проєктами.
- `src/js/app.js` — запуск застосунку, обробники подій, дії із завданнями та списками; застосування вибраної дати до завдань і проєктів.

Для роботи із завданнями й списками шукайте правила в `model.js`, відображення в `ui.js`, а обробники дій в `app.js`. Для проєктів дивіться `projects.js`; для жестів — `gestures.js`; для календаря й часу — `date-picker.js` (їхні обробники подій залишаються в `app.js`).

Порядок об’єднання файлів задає `JS_FILES` у `scripts/build.py`. Файли поки не є ES-модулями: їхній код виконується в одному вбудованому скрипті та використовує спільну область видимості.
